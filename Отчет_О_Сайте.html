Остановки Бреста — Электронный атлас

Выполнил: Белорусец Адам, учащийся 9 «Б» класса
Проект: Интерактивная карта остановок микрорайона Речица
Инструменты: Visual Studio Code, HTML, CSS, JavaScript
Брест, 2026

1. Что это такое?

«Остановки Бреста» — это интерактивное веб-приложение (электронный атлас), которое показывает все остановки общественного транспорта микрорайона Речица на карте. Сайт создан для того, чтобы жители и гости города могли быстро находить нужную остановку, смотреть её состояние, покрытие, наличие инфраструктуры и расписание автобусов.

Сайт работает на любом устройстве: на компьютере, планшете и телефоне. Он не требует установки — достаточно открыть ссылку в браузере.

2. Где и как делал?

Сайт написан в Visual Studio Code на языках HTML, CSS и JavaScript. Для отображения карты использована библиотека MapLibre GL (открытая и бесплатная альтернатива Google Maps). Данные об остановках хранятся в самом коде (массив STOPS).

Дизайн выполнен в стиле macOS 26 Tahoe (жидкое стекло, тёмная тема, плавные анимации). Это делает сайт не только функциональным, но и эстетичным.

Сайт задеплоен на GitHub Pages — это бесплатный хостинг, который позволяет открыть сайт по ссылке:

Ссылка на сайт: https://adambelarusets-bot.github.io/brest-stops/

3. Что происходит на сайте? (Как работает)

Когда пользователь открывает сайт, он видит карту с маркерами остановок. Каждый маркер — это цветной кружок, который показывает состояние остановки:

  • Зелёный — хорошее состояние.
  • Оранжевый — удовлетворительное.
  • Красный — требует внимания.

Если нажать на маркер, появляется маленькое окно (снизу слева) с краткой информацией: название, адрес, автобусы, состояние, покрытие, сквер, магазин, урны, лавочки, деревья, тренажеры.

Если нажать кнопку «Подробнее», открывается большое окно (на весь экран) с полным расписанием, описанием, маршрутами и мини-картой.

Также на сайте есть поиск (по названию или номеру автобуса) и кнопка GPS (показывает твоё местоположение на карте).

4. В чём смысл? (Зачем нужен сайт)

Сайт решает несколько задач:

  • Для жителей: быстро найти остановку, узнать, какие автобусы ходят, и когда будет следующий.
  • Для гостей города: не заблудиться в незнакомом районе.
  • Для городских служб: увидеть, какие остановки требуют ремонта (по цвету маркера).
  • Для исследования: сайт создан в рамках НПК по географии, чтобы показать, как можно визуализировать данные об остановках.

5. Почему полезно и удобно?

  • Всё в одном месте: карта, расписание, инфраструктура — не нужно искать по разным сайтам.
  • Наглядно: цветные маркеры сразу показывают состояние остановок.
  • Быстро: сайт загружается за 1-2 секунды.
  • Удобно: работает на телефоне (адаптивный дизайн).
  • Современно: дизайн в стиле macOS 26 (жидкое стекло).
  • Бесплатно: сайт работает на GitHub Pages, не требует оплаты хостинга.

6. Особенности интерфейса

Интерфейс сайта состоит из нескольких элементов:

  • Шапка: логотип «Брест», строка поиска, кнопки стиля карты, слоёв и GPS.
  • Карта: на весь экран, с тёмным стилем (как в macOS).
  • Маленькое окно: появляется при клике на маркер, показывает краткую информацию.
  • Большое окно: открывается по кнопке «Подробнее», показывает полное расписание и описание.
  • Легенда: в правом нижнем углу, объясняет цвета маркеров.
